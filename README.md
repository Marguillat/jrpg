# JavaRPG

## Installation
### Dépendances
- Java version : ``25.0.1``
- JVM runner : ``Eclipse Temurin``
- Build tool : ``Maven``

### Lancer le projet (dev)
1. Cloner le repo : 
2. Vérifier avec maven
````shell
./mvnw verify
````
3. Packager avec maven
````shell
./mvnw package
````
4. Lancer le jar
````shell
java -jar <nomDuJarDans/Target>.jar
````
